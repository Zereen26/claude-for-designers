# Project contract: <client name>

**What this file is for:** the rules that are true about this client and nobody else. Who they are, who their users are, what is already settled, what they reject, and what finished means.

**Why Claude needs it:** it reads this file on every task inside this folder. Whatever you leave out, it fills in with an average.
