# Career Vault

This folder is about you, not the project. Classes 7 and 8 produce the artifacts in here. You also keep coming back to update them every time you finish a project.

The premise: most junior designers can do the work but cannot articulate it. The vault fixes that. Five files, all templates with prompts. You fill them in. You update them. Over a year they become the most useful folder in this workspace.

## What lives in this folder

| File | When you touch it | What it captures |
|---|---|---|
| `01-positioning.md` | Class 7 + ongoing | Who you are, what you stand for, what makes you not interchangeable |
| `02-portfolio-story.md` | Class 7 + after each project | The narrative for one project: what you decided, not what AI did |
| `03-resume.md` | Class 8 + every job hunt | Resume content built from your projects, not from job descriptions |
| `04-interview-answers.md` | Class 8 + before every interview | Behavioral answers, the cheating-objection response, situational answers |
| `05-linkedin-content.md` | Class 8 + ongoing | LinkedIn bio, post templates, outreach DMs |

## How it pairs with `projects/`

For each project in `projects/`, you should have a corresponding portfolio story. Class 7 walks you through how to write the EduBridge story. After that, every real project you do, the story goes here.

```
projects/edubridge/      ← the work
career-vault/02-portfolio-story.md  ← the story about the work
```

When a recruiter asks "tell me about a project," you do not improvise. You open `02-portfolio-story.md`, pick the right project, and talk from the structured story you already wrote.

## The "AI did this for me" problem

Half of this folder exists to solve one problem: how do you talk about work where Claude was your collaborator without sounding like you were just along for the ride?

Answer: by being explicit about what you directed and decided. Every file in this vault is structured to force you to name your decisions, not the tool's outputs. By Class 8 you should be comfortable saying "I directed, I decided, I rejected, I shipped": and meaning it.
