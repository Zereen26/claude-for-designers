Problem

Kothay atke jacche

Chronic health issue-er jonno jara regular medicine khan (beshirvag khetre elderly patient), tara shadharonoto reorder koren jokhon current supply shesh hoye jay — mane already lete geche.

Karon hote pare:

  • Boyosher karone mone rakhte koshto hoy
  • Onek gulo medicine ekshathe hishab rakha kothin
  • Doctor dose change / add / edit korte paren, jekono somoy
  • Bhul kore kono din dose skip hoye jete pare

Fole ja ghote:

  • Patient stress feel koren
  • Ekdin dose miss hole chronic condition-e serious issue hote pare
  • Caregiver jini dure thaken, tini anxiety o guilt feel koren

The feature we're adding

Solution direction
  1. Checkout-er por shuru hoy emon ekta refill system
  2. Supply shesh hoye jaoar age-i patient o caregiver — dujon-keই reminder deya
  3. Reminder-er shathe ekta readymade cart deya, jekhane proyojoniyo sob medicine already add kora thakbe

1Checkout date theke reorder date — eta ekbar-e calculate kore dile cholbe na

App-ke shudhumatro "checkout date + X din" hishab kore next reorder date dhoriye dile cholbe na, karon teen-ta variable ache jeta cycle-er majhkhane change hote pare:

  • Doctor dose change korte paren (barano/komano)
  • Koto medicine "left" ache — eta accurately track korte hobe
  • Patient bhule kono din skip korte paren

Tai system-ta emon hote hobe: static, one-time calculation na — correctable. Kono input change hole system nijeke adjust korte parbe, prottekbar notun kore stop hoye giye recalculate na kore.

2Calculation-ta actually kivabe hobe

App nijer theke "koto diner medicine ache" bujhbe na — eta 2-ta input theke ashbe:

(a) Quantity kena hoyeche

Strip / tablet count — jeta cart-e kena hoyeche.

(b) Prescribed dosage

Daily koto bar, ekbar-e koto tablet — prescription-e lekha thake.

1 strip = 10 tablets
Dosage: daily 2 tablet
Continue for: 7 days
→ 14 tablet lagbe (2 × 7) — 1 strip-e hoye jabe, 6-ta tablet baki thakbe

Eta theke App nijei calculate korte parbe: date, medicine name, quantity. Kintu "daily koto bar, koto din khete hobe" — eta prescription-nirvor, App guess korte parbe na. Eta user input hobe:

How many tablet per dose?
123
How many times a day?
1×2×3×
For how many days?
71430
Edge case

Doctor 30 diner jonno bolechen, kintu user matro 7 diner jonno-i kinte chan (poysha/stock-space-er karone) — tahole prothome 7-din-er hisheb-e cart banabe, kintu reorder-cart-e clearly mention thakte hobe je baki 23 din-er oshudh-o lagbe, jate patient bhule na jay.

3Doctor jodi mid-cycle-e dose change kore

Ei ta-ই sobcheye tricky part — 30 din-er medicine kena hoyeche, kintu day 15-te doctor dose change kore dile ki hobe:

ChangeEffectApp-ke ki korte hobe
Dose barale Medicine druto shesh hobe — prediction date-er age-i shesh hobe Reminder-o age-i pathate hobe; purono reminder cancel kore notun date set korte hobe
Dose komale Medicine onek beshi din cholbe Reorder-er shomoy hishebe onek medicine already baki thakbe — over-order avoid korte hobe
Solution

User-ke jekono shomoy (checkout-er shomoy-e na shudhu) dosage update korar ekta easy option dite hobe. Update korle system shathe shathe notun kore calculate kore countdown ar reorder date thik kore dibe — wait na kore.

Reminder date  =  Medicine-shesh-hobar-date − delivery time (~2 din) − ideal buffer day

Onnanno open consideration

Ekhono decide hoyni
  • Emergency update button: medicine bazare unavailable thakle, user-ke manually janai dewar option
  • Price: reorder cart-e price koto ta dekhano proyojon
  • Stock threshold: user 7 diner stock rakhben naki 30 diner — eta app default nakay user-choice?
  • Dashboard: shob medicine-er status ekshathe ekjagai dekhar jonno lagbe
  • Same account, multiple patient: ekই account-e 2/3 jon-er reminder alada rakhte hobe — kar jonno kon reminder ta clear hote hobe
